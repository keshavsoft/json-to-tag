03 · ELEMENT BUILDER

The element is assembled in stages.

The v4 element builder separates creation from text, properties, attributes, classes and children.

0 Create→1 Text→2 Properties→3 Attributes→4 Classes→5 Children
StageInputPurpose
0tagNameCreate native element.
1textContentSet visible text.
2propertiesApply DOM state.
3attributesApply HTML attributes.
4classListApply CSS classes.
5childrenAccept child nodes.

Source shape

const element = createElement({inTagName: localSpec.tagName});
applyTextContent({inElement: element, inTextContent: localSpec.textContent});
applyProperties({inElement: element, inProperties: localSpec.properties});
applyAttributes({inElement: element, inAttributes: localSpec.attributes});
applyClassList({inElement: element, inClassList: localClassList});
appendChildren({inElement: element, inChildren: localSpec.children});
return element;

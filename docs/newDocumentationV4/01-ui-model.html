01 · UI MODEL

A UI is a tree of small pieces.

The library can describe a screen as small DOM elements. Each element has a tag, optional content, DOM details and children.

Invoice

2 items

Piece A — parent

The card is the parent element.

{ "tagName":"div", "classList":["mini"] }
Invoice

Piece B — text

Visible text is data on the element.

{ "tagName":"strong", "textContent":"Invoice" }

Piece C — browser detail

Attributes and properties describe browser-facing state.

{ "tagName":"button", "textContent":"Open", "attributes":{"type":"button"} }

02 · TRANSLATION

One call starts the build.

The v4 public entry point receives the specification and passes it into the build dispatcher.

const element = window.ks.jsonToTag.buildSpecElement({
  tagName: "h2",
  textContent: "Invoice"
});

1 · Public entry

The entry function selects spec, inSpec, or the object itself, then calls buildSpec.

const localSpec = localArgs?.spec ?? localArgs?.inSpec ?? localArgs;
const element = buildSpec({ inSpec: localSpec });

2 · Dispatch

spec→dispatch→null / DOM / array / single
if (isNullOrUndefined({inSpec})) return null;
if (isDomNode({inSpec})) return inSpec;
if (isSpecArray({inSpec})) return buildSpecArray({inSpec});
return buildSingleElement({inSpec});

3 · Single element

A normal object reaches buildSingleElement, which uses the element builder and then assembles nested children.

const elementBuilt = domElementBuilder({ inSpec: localSpec });
// children are built and appended
return elementBuilt;

Public API → dispatcher → single-element builder is the boundary between input data and native DOM construction.

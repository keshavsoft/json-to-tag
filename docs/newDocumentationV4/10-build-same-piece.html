10 · CDN BUILD

Build the same piece

The JSON describes the same UI, the CDN provides the builder, and the browser receives a native DOM element.

Build code

<script src="https://keshavsoft.github.io/json-to-tag/dist/v4/min.js"></script>

const spec = {
  tagName: "div",
  attributes: { id: "test-content" },
  children: [
    { tagName: "label", textContent: "Name" },
    { tagName: "p", textContent: "Test Content" }
  ]
};

const element =
  window.ks.jsonToTag.buildSpecElement(spec);

document.querySelector("#browser-output")
  .replaceChildren(element);

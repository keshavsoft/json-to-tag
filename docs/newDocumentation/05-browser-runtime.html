05 · BROWSER RUNTIME

Load once. Build in the browser.

The browser page loads the v4 bundle through CDN and then calls the registered browser API.

1 · Load

<script src="https://keshavsoft.github.io/json-to-tag/dist/v4/min.js"></script>

2 · Get the entry

const buildSpecElement = window.ks.jsonToTag.buildSpecElement;

3 · Build and mount

const element = buildSpecElement({
  tagName: "p",
  textContent: "Hello from json-to-tag"
});
document.body.append(element);

Runtime flow

<script>→CDN→global API→builder→DOM

Global registration

registerGlobal({
  inFuncDefinition: buildSpecElement,
  inReviewSpec: reviewSpec
});

This page defines only the browser loading model. Internal construction remains on the Builder page.

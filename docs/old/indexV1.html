Quick Installation & Scaffolding

npm install @keshavsoft/json-to-tag
# or scaffold directly with NPX:
npx @keshavsoft/json-to-tag

ES Module & Browser Global Usage

// v4 Direct Spec Input (single argument - no object wrapper needed!):
import { buildSpecElement } from "@keshavsoft/json-to-tag";
const button = buildSpecElement(spec);

// Browser Global (registered automatically onto window.ks.jsonToTag):
const form = window.ks.jsonToTag.buildSpecElement(spec);
document.getElementById("container").append(form);

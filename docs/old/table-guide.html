💡 Jargon Buster (Terms Explained in Human English)

What is a CDN?

CDN stands for Content Delivery Network. In simple words: it is a web address (URL) where pre-built programs live. Instead of downloading heavy software, your web browser downloads the tool instantly in 0.1 seconds from the web link.

What is a JSON file?

JSON is just plain text structured with brackets { } and labels like "name": "Alex". It is the world's most popular way to save lists and tables because any computer can read it instantly.

What is <thead> and <tbody>?

In a table, <thead> is the top "Header" row (e.g., Name, Age, Country). <tbody> is the "Body" where all the actual rows of people or products sit.

What does ${title} or ${value} mean?

It is a placeholder (like a fill-in-the-blank on a form). When the table is created, the computer replaces ${title} with the real column name, and ${value} with your actual data.

Chapter 2

The 3 Simple Files You Need

Take a look at each file. You can copy and paste them directly into your project!

File 1: data.json

Contains two things: the list of column titles (columns) and the list of rows (data).

Payload 
{
  "columns": [
    { "title": "#", "field": "id" },
    { "title": "Employee Name", "field": "name" },
    { "title": "Department", "field": "department" },
    { "title": "Role", "field": "role" }
  ],
  "data": [
    { "id": "1", "name": "Karthik Raja", "department": "Engineering", "role": "Architect" },
    { "id": "2", "name": "Praveen Kumar", "department": "Design", "role": "UI Lead" },
    { "id": "3", "name": "Srinivas Rao", "department": "Product", "role": "Manager" }
  ]
}
🔍 Plain English Explanation:
  • columns: Tells the table what headers to print across the top row (e.g. "#", "Employee Name", "Department", "Role").
  • data: An array of people. Each person has an id, name, department, and role.
  • Want to add another employee? Simply add another line inside data!

File 2: structure.json

The visual blueprint. It tells the compiler to create a table, loop the columns, and loop the rows.

Blueprint 
{
  "tagName": "table",
  "attributes": {
    "class": "table table-striped table-hover table-bordered mb-0"
  },
  "children": [
    {
      "tagName": "thead",
      "attributes": { "class": "table-dark" },
      "children": [
        {
          "tagName": "tr",
          "jsonToSpec": {
            "operation": "loopArray",
            "source": "columns",
            "template": {
              "tagName": "th",
              "textContent": "${title}"
            }
          },
          "children": []
        }
      ]
    },
    {
      "tagName": "tbody",
      "jsonToSpec": {
        "operation": "loopArray",
        "source": "data",
        "template": {
          "tagName": "tr",
          "jsonToSpec": {
            "operation": "loopObject",
            "source": "data",
            "template": {
              "tagName": "td",
              "textContent": "${value}"
            }
          },
          "children": []
        }
      },
      "children": []
    }
  ]
}
🔍 Plain English Explanation:
  • tagName: "table": Says "create an HTML table".
  • class: "table table-striped...": Uses Bootstrap styling for professional zebra stripes and hover highlights.
  • loopArray with source: "columns": Takes each column in your data and automatically makes a header cell <th> with its title!
  • loopArray with source: "data": Takes each person in your data and creates a new row <tr>!
  • loopObject with template: <td>${value}</td>: Fills each cell in the row with the person's values!

File 3: index.html

The web page that brings everything together using CDN links. No node_modules, no npm install!

Main HTML 
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>My Table from JSON</title>

  <!-- 1. Bootstrap CDN for styling -->
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body class="bg-light p-4">

  <div class="container py-4">
    <h2 class="mb-3 font-bold">Employee Directory</h2>

    <!-- Placeholder where our table will appear -->
    <div id="table-container" class="card shadow-sm p-3">
      <div class="text-muted text-center py-4">Loading table...</div>
    </div>
  </div>

  <!-- 2. JavaScript to fetch and render via CDNs -->
  <script type="module">
    // Import compiler & renderer directly from CDNs
    import buildSpecElement from "https://keshavsoft.github.io/json-to-spec/dist/v23/min.js";
    import "https://keshavsoft.github.io/json-to-tag/dist/v4/min.js";

    async function init() {
      // Step A: Load the 2 JSON files
      const [structure, data] = await Promise.all([
        fetch('./structure.json').then(r => r.json()),
        fetch('./data.json').then(r => r.json())
      ]);

      // Step B: Merge structure + data into a spec
      const spec = buildSpecElement({ specJson: structure, dataJson: data });

      // Step C: Render it directly onto the webpage!
      const tableHtml = window.ks.jsonToTag.buildSpecElement(spec);
      const container = document.getElementById('table-container');
      container.innerHTML = '';
      container.appendChild(tableHtml);
    }

    init();
  </script>
</body>
</html>
🔍 Plain English Explanation:
  • Bootstrap CSS Link: Gives your table clean borders, padding, and fonts automatically.
  • import buildSpecElement from "...": Loads the compiler tool from the web in 1 line.
  • fetch('./structure.json'): Reads your blueprint.
  • buildSpecElement(...): Merges your data with the blueprint.
  • container.appendChild(...): Inserts the generated table right into your webpage!

                Chapter 5
                
Frequently Asked Questions & Easy Fixes

                

                    Common questions beginners ask when building their first table.
                

            


            

                
                

                    

                        ❓ Why is my table blank when I double-click index.html on my computer?
                    

                    

                        This is caused by modern browser security called CORS. Browsers block the JavaScript fetch('./data.json') command when running directly from your hard drive (file:///).

                        How to fix: Either download the All-In-One Standalone Starter above (which embeds the data directly), or open your folder with VS Code and use the free Live Server extension.
                    

                


                
                

                    

                        ❓ How do I add a new column (like "Phone Number" or "Salary")?
                    

                    

                        You only need to edit data.json! 
                        1. Add { "title": "Phone", "field": "phone" } inside the "columns" array. 

                        2. Add "phone": "555-0199" to each person inside "data". 

                        Because structure.json is dynamic, it will automatically create the new header and cells for you!
                    

                


                
                

                    

                        ❓ Can I customize the colors and styles?
                    

                    

                        Yes! In structure.json, change the class attribute on the table tag. For example:
                        
    
                            
  • class: "table table-dark table-hover" for a sleek dark mode table.
    • 
                            
  • class: "table table-bordered table-sm" for a compact borders table.
    • 
                            
  • class: "table table-success" for a soft green table.
    • 
                        

                    

                


                
                

                    

                        ❓ Do I have to pay anything for the CDNs?
                    

                    

                        No, all the CDNs used (Bootstrap on jsDelivr, json-to-spec, and json-to-tag on GitHub Pages) are 100% free and open source with an MIT license.

Build the same piece

The JSON describes the same UI, the CDN provides the builder, and the browser receives a native DOM element.

How is this loaded?
This page demonstrates the CDN approach: a standalone browser bundle loaded via a <script> tag with zero build tools, zero Node.js, and zero npm install required. For Node.js / bundler environments, see the module comparison below.

1 · CDN Build (Direct Browser HTML)

Load the library bundle directly via CDN in your HTML. The CDN registers the global API on window.ks.jsonToTag. 

<!-- 1. Load json-to-tag engine directly from CDN (no Node.js needed) -->
<script src="https://keshavsoft.github.io/json-to-tag/dist/v4/min.js"></script>

<script>
// 2. Define the UI as a JSON specification
const spec = {
  tagName: "div",
  attributes: { id: "test-content" },
  children: [
    { tagName: "label", textContent: "Name" },
    { tagName: "p", textContent: "Test Content" }
  ]
};

// 3. Global function exposed by CDN bundle:
const element = window.ks.jsonToTag.buildSpecElement(spec);

// 4. Mount the native DOM element into the page:
document.querySelector("#browser-output").replaceChildren(element);
</script>

2 · Node.js / ES Module (npm package)

If you are working in Node.js or a bundler project (Vite, Webpack, Next.js), install from npm and import as an ES module instead: 

# Install via npm:
npm install @keshavsoft/json-to-tag

// In your JavaScript / TypeScript application:
import { buildSpecElement } from "@keshavsoft/json-to-tag";
// Or if copied locally via npx:
// import { buildSpecElement } from "./json-to-tag/index.js";

const spec = {
  tagName: "div",
  attributes: { id: "test-content" },
  children: [
    { tagName: "label", textContent: "Name" },
    { tagName: "p", textContent: "Test Content" }
  ]
};

const element = buildSpecElement(spec);
document.querySelector("#browser-output").replaceChildren(element);

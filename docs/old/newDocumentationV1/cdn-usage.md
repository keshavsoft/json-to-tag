# CDN Usage

`json-to-tag` can be loaded directly in a browser with a script tag.

```html
<script src="https://keshavsoft.github.io/json-to-tag/dist/v4/min.js"></script>
```

The browser global is available as:

```javascript
window.ks.jsonToTag
```

The main browser API is:

```javascript
window.ks.jsonToTag.buildSpecElement(spec)
```

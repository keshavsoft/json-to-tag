# Documentation Structure

```text
json-to-tag-browser-documentation/
├── README.md
├── DOCUMENTATION-STRUCTURE.md
└── docs/
    ├── index.html
    ├── getting-started.md
    ├── cdn-usage.md
    ├── specification.md
    ├── architecture.md
    ├── browser-flow.md
    ├── examples.md
    └── tags.html
```

`docs/index.html` is the main visual documentation page.

The supporting Markdown pages separate the main topics so they can later be converted into individual documentation pages if required.

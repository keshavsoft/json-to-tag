Load the browser build using a script tag.

02 · Define

Create a serializable JSON specification for your element.

03 · Render

Build the specification and append the returned DOM element.

CDN Usage

No package installation or bundler is required for the browser workflow.

<script src="https://keshavsoft.github.io/json-to-tag/dist/v4/min.js"></script>
Browser API: after the library is loaded, the browser global is available through window.ks.jsonToTag.
<script src="https://keshavsoft.github.io/json-to-tag/dist/v4/min.js"></script> <script> const element = window.ks.jsonToTag.buildSpecElement(spec); document .getElementById("app") .appendChild(element); </script>

JSON Specification

A specification describes the DOM element that should be created.

Property Purpose Example
tagName HTML element to create "button"
textContent Text inside the element "Save"
classList CSS classes "btn btn-primary"
attributes HTML attributes { type: "button" }
properties DOM properties { value: "John" }
children Nested specifications [ ... ]

Browser Architecture

The runtime flow from JSON data to a native DOM node.

JSON Specification │ ▼ buildSpecElement(spec) │ ▼ buildSpec() │ ├── Single specification │ └── Element Builder │ ├── Array specification │ └── Build each item │ └── Existing DOM Node └── Reuse Node │ ▼ Native DOM Element │ ▼ document.append(...)

Complete Browser Example

A complete page using only HTML, JavaScript, and the CDN build.

<!DOCTYPE html> <html> <body> <div id="app"></div> <script src="https://keshavsoft.github.io/json-to-tag/dist/v4/min.js"></script> <script> const spec = { tagName: "button", textContent: "Click Me", classList: "btn btn-primary", attributes: { type: "button" } }; const button = window.ks.jsonToTag.buildSpecElement(spec); document .getElementById("app") .appendChild(button); </script> </body> </html>

Nested UI

Specifications can contain children, allowing complete UI structures to be described as JSON.

const spec = { tagName: "div", classList: "card", children: [ { tagName: "h2", textContent: "User Profile" }, { tagName: "p", textContent: "Created from JSON." }, { tagName: "button", textContent: "Open" } ] }; const card = window.ks.jsonToTag.buildSpecElement(spec); document.getElementById("app").appendChild(card);

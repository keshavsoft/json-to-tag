Start in two minutes

Install the package, describe a button as data, build it, and append the resulting element.

npm install @keshavsoft/json-to-tag
import { buildSpecElement } from "@keshavsoft/json-to-tag";

const spec = {
  tagName: "button",
  classList: "btn btn-primary",
  textContent: "Save",
  attributes: { type: "button" }
};

const button = buildSpecElement({ inSpec: spec });
document.body.appendChild(button);

The specification model

Six fields cover the core DOM responsibilities: element type, text, classes, attributes, properties, and children.

FieldTypeRole
tagNamestringHTML element name
textContentstring | numberDirect text content
classListstring | string[]CSS classes
attributesobjectHTML attributes
propertiesobjectDirect DOM property assignment
childrenarrayNested specs, text, nodes, or nested arrays

How the engine works

The current v4 implementation follows a readable pipeline rather than hiding all behavior in one function.

NormalizeResolve spec / inSpec / direct input
DispatchNull, Node, Array, or spec
BuildCreate one element
ApplyRun six builder stages
RecurseCompile children
Stage 0

Create element

0.createElement.js creates the element and contains the checkbox alias.

Stage 1–2

Text + properties

Direct text is applied, then JavaScript properties are assigned to the DOM object.

Stage 3–4

Attributes + classes

Attributes use HTML attribute operations; classes are normalized and added through classList.

Stage 5

Append children

Child nodes and primitive text are appended after recursive child resolution.

Review without rendering

reviewSpec provides a separate path for analyzing a specification against the repository's tag catalog.

import { reviewSpec } from "@keshavsoft/json-to-tag";

const result = reviewSpec({ inSpec: {
  tagName: "div",
  children: [
    { tagName: "h1", textContent: "Dashboard" },
    { tagName: "button", textContent: "Open" }
  ]
}});

console.log(result.totalTags);
console.log(result.tagCounts);
console.log(result.areAllTagsPresent);
console.log(result.unrecognizedTags);

# json-to-tag — Documentation Package

A redesigned documentation experience for **@keshavsoft/json-to-tag**.

## Included

- `docs/index.html` — polished documentation landing page
- `docs/getting-started.md` — installation and first render
- `docs/specification.md` — JSON specification model
- `docs/architecture.md` — v4 rendering flow and builder stages
- `docs/review.md` — specification review API
- `docs/catalog.md` — tag catalog and documentation tools
- `docs/examples.md` — practical form, card, and table examples
- `docs/migration.md` — notes for moving from older docs/API examples

## Design direction

The old documentation works as a directory of tools. This version is organized as a learning path:

**Understand → Install → Write a Spec → Render → Review → Explore the Catalog**

The content stays grounded in the current repository while presenting the project in a cleaner product-documentation style.

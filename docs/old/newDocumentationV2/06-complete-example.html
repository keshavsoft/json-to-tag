06 · BUILD

Build a small UI from one specification.

This page combines the earlier concepts without repeating their explanations.

Invoice

2 items

Complete page

<div id="app"></div>

<script src="https://keshavsoft.github.io/json-to-tag/dist/v4/min.js"></script>
<script>
const spec = {
  tagName: "div",
  classList: ["mini"],
  children: [
    {tagName:"strong", textContent:"Invoice"},
    {tagName:"p", textContent:"2 items"},
    {tagName:"button", textContent:"Open",
     attributes:{type:"button"}}
  ]
};

const element =
  window.ks.jsonToTag.buildSpecElement(spec);

document.querySelector("#app").append(element);
</script>

Resulting tree

#app └─ div.mini ├─ strong → Invoice ├─ p → 2 items └─ button[type="button"] → Open

Documentation story
HTML → UI structure → JSON specification → CDN build → native DOM

One UI. Three approaches.

Same browser output. Different construction method.

01 · ORIGINAL HTML

Write the markup

The browser parses HTML directly. 
<div id="test-content">
  <label>Name</label>
  <p>Test Content</p>
</div>
Browser output

Test Content

02 · VANILLA JAVASCRIPT

Create nodes manually

Native DOM APIs create each node. 
const div = document.createElement("div");
const label = document.createElement("label");
const text = document.createElement("p");

label.textContent = "Name";
text.textContent = "Test Content";

div.append(label, text);
Browser output

Test Content

03 · JSON-TO-TAG CDN

Describe, then build

JSON describes the tree; CDN creates DOM. 
const spec = {
  tagName: "div",
  children: [
    { tagName: "label",
      textContent: "Name" },
    { tagName: "p",
      textContent: "Test Content" }
  ]
};

window.ks.jsonToTag
  .buildSpecElement(spec);
Browser output

Test Content

Key idea: the output is the same. The third approach moves the UI description into JSON and lets the CDN build the native DOM.

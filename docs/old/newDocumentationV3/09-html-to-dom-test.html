09 · HTML → DOM TEST

One small HTML piece, built through CDN.

A label and test content are kept intentionally small so the complete conversion story is visible.

1 · HTML target

<div id="test-content">
  <label>Name</label>
  <p>Test Content</p>
</div>

2 · Label + test content

Test Content

3 · Same structure as JSON

{
  "tagName": "div",
  "attributes": {"id": "test-content"},
  "children": [
    {"tagName": "label", "textContent": "Name"},
    {"tagName": "p", "textContent": "Test Content"}
  ]
}

4 · Build through CDN

<script src="https://keshavsoft.github.io/json-to-tag/dist/v4/min.js"></script>

const spec = {
  tagName: "div",
  attributes: { id: "test-content" },
  children: [
    { tagName: "label", textContent: "Name" },
    { tagName: "p", textContent: "Test Content" }
  ]
};

const element =
  window.ks.jsonToTag.buildSpecElement(spec);

5 · Add to DOM

document.body.append(element);

6 · Browser output

The browser receives the native DOM element produced by the CDN build. The rendered result is shown below.

Test Content

Rendered DOM └─ div#test-content ├─ label → Name └─ p → Test Content

The story

HTML→Label→Test Content→JSON→CDN→DOM
#test-content ├─ label → Name └─ p → Test Content
The HTML is the target structure. The specification describes it. The CDN builds the native DOM node. The final step inserts that node into the page.
HTML → specification → CDN build → native DOM
